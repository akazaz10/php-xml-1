# Recomendación inicial

- Ejecutar "test-unitarios.html" para correr las pruebas rápidas por defecto.


# Archivos

- **main.php:** Archivo principal, controla la lógica principal y decide qué hace cada acción.
- **userFunctions.php:** Contiene todas las funciones relativas al usuario, son funciones como validación de usuario, comprobación de existencia, etc.
- **connectionsFunctions.php:** Contiene todas las funciones relativas a las conexiones, funciones como añadir una nueva conexión y cerrar una conexión activa.
- **config.php:** Contiene una función que se utiliza para formatear un archivo xml, esta función es utilizada tanto por usersFunctions así como también connectionsFunctions. También contiene el cambio de zona horaria.
- **/xml:** Contiene los archivos xml que se utilizan para el sistema.
- **/src:** Contiene el documento html para mostrar los tests unitarios, y también contiene la hoja de estilos.
